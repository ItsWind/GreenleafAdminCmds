# GreenleafAdminCmds
A Vintage Story server side mod made for Greenleaf to create new, handy admin commands

In-Game Commands:

/tpback This command will teleport admin back to location they were previously at before teleporting.

/tpentityid -e ENTITYID This command will teleport any loaded entity with ENTITYID to the admin's location. The entity MUST be in a loaded chunk.

/tagboatcreator -p USERNAME This command will tag the boat looked at as created by the USERNAME specified. The player with the username MUST have been on the server at some point.
